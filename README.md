# PropVoice- A.I

An AI-powered Real Estate Sales Assistant that interacts with customers, understands their requirements, qualifies leads, and provides intelligent property recommendations using Google Gemini AI.

<img width="1898" height="971" alt="image" src="https://github.com/user-attachments/assets/7f52e821-3311-4f1b-9358-0b60c8275eaa" />


### Features

- AI-powered real estate assistant
- Natural conversation (Hindi, Hinglish & English)
- Lead qualification
- Automatic lead scoring
- Property recommendation
- SQLite database
- Conversation memory
- REST APIs
- Live deployment
